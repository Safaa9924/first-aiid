# First Aid RAG Assistant

A hybrid Retrieval-Augmented Generation (RAG) pipeline built on the
*First Aid Reference Guide, 4th Edition* (St. John Ambulance Canada).

The pipeline loads the source PDF, cleans and chunks it, builds three
complementary retrieval indexes (TF-IDF, BM25, dense embeddings),
stores the embeddings in a persistent Chroma vector database, and
answers user questions (Arabic or English) with a grounded, cited
answer generated by a local LLM (Ollama).

## Pipeline Stages

| File | Stage | Description |
|---|---|---|
| `01_documents.py` | Document Loading | Parses the PDF with Docling, preserving headings/structure. |
| `02_preprocessing.py` | Preprocessing | Cleans text artifacts, removes front matter, normalizes structure. |
| `03_chunking.py` | Chunking | Adaptive semantic chunking with metadata tagging. |
| `04_vector_representation.py` | Vector Representation | Builds TF-IDF, BM25, and embedding indexes. |
| `05_create_chroma_store.py` | Vector Store | Populates a persistent Chroma collection. |
| `06_retrieve_context.py` | Retrieval | Query translation/expansion, hybrid retrieval, cross-encoder reranking, context packaging. |
| `07_prompting.py` | Generation | Prompt construction, Ollama LLM generation, bilingual grounded answer + citations. |
| `streamlit_app.py` | App | Interactive Streamlit UI tying the whole pipeline together. |

## Two requirements files

- **`requirements.txt`** — lightweight, only what `streamlit_app.py`
  needs at runtime. This is the one Streamlit Cloud (and any
  deployment) installs automatically.
- **`requirements-full.txt`** — everything, including `docling` and
  `chromadb`, which are only needed *once* locally to build the index
  (stages 01–05). Installing these on the deployment target just
  slows down the build for no benefit, since the app never calls them.

## Setup (building the index locally)

```bash
pip install -r requirements-full.txt
```

Make sure [Ollama](https://ollama.com) is running locally with the
`llama3.2` model pulled:

```bash
ollama pull llama3.2
```

## Building the Index

Update `PDF_PATH` in `01_documents.py` to point to your local copy of
`First_aid_reference_guide_V4.1_Public.pdf`, then run the stages in
order:

```bash
python 01_documents.py
python 02_preprocessing.py
python 03_chunking.py
python 04_vector_representation.py
python 05_create_chroma_store.py
```

Each stage reads the previous stage's output from `data/` and writes
its own artifacts there (`raw_text.txt`, `cleaned_text.txt`,
`chunks.csv`, `tfidf_index.pkl`, `bm25_index.pkl`,
`embedding_matrix.npy`) plus the persistent `chroma_db/` folder.

`streamlit_app.py` only reads `chunks.csv`, `tfidf_index.pkl`,
`bm25_index.pkl` and `embedding_matrix.npy` — **these four files must
be committed to git** (check `.gitignore` doesn't exclude `data/`),
since Streamlit Cloud only has what's in the repo, not anything
generated on your machine.

## Running the App

```bash
pip install -r requirements.txt   # app-only deps, already covered by requirements-full.txt if installed above
streamlit run streamlit_app.py
```

Ask a first-aid question in Arabic or English and get a grounded,
bilingual answer with a source-confidence report.
